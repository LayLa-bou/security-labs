# Security Labs

## Description
This repository contains academic cybersecurity lab exercises and practical work completed during my 2nd year coursework. Each file documents a specific lab with objectives, steps, tools used, and learning outcomes.

## Labs Included
1. **TP1: Network Security Basics**  
   Learn about network protocols, OSI model, and basic scanning techniques.

2. **TP2: Linux Security Basics**  
   Explore Linux file system security, permissions, and user management.

3. **TP3: Basic Scanning**  
   Practice network reconnaissance using Nmap to identify hosts, open ports, and services.

## Objectives
- Apply theoretical cybersecurity concepts in practice
- Develop hands-on skills with tools like Nmap, Linux commands, and network monitoring
- Document lab exercises in an organized and professional manner

## Learning Outcomes
- Understand network and system security fundamentals
- Perform basic security assessments and analysis
- Practice academic lab work in a safe, controlled environment

## Context
All content in this repository is part of academic coursework as a 2nd year Cyber Security student.
