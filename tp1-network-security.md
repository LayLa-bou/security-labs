# TP1: Network Security Basics

## Objective
Practice basic network security concepts and understand the fundamentals of network protection.

## Lab Steps
1. Study the OSI model and its layers.
2. Learn about common network protocols (TCP/IP, HTTP, HTTPS, DNS).
3. Perform basic network scanning using Nmap (internal lab environment).
4. Identify open ports and services on test machines.

## Tools Used
- Nmap
- Wireshark (for traffic observation)
- Virtual lab machines

## Learning Outcomes
- Understand network architecture and protocols.
- Perform basic scanning to identify active services.
- Learn the importance of securing open ports and monitoring traffic.

## Context
Academic lab work – 2nd year Cyber Security student.
