# TP2: Linux Security Basics

## Objective
Learn basic Linux security concepts, permissions, and user management as part of 2nd year Cyber Security coursework.

## Lab Steps
1. Explore Linux file system and permissions:
   - Read, write, execute for user, group, others
2. Practice changing file permissions using `chmod` and `chown`
3. Manage user accounts:
   - Create, delete, and modify users
   - Assign users to groups
4. Learn about sudo privileges and secure administration
5. Explore basic firewall setup using `ufw` or `iptables`

## Tools Used
- Linux (Ubuntu / Kali VM)
- Terminal / Shell commands
- Virtual lab machines

## Learning Outcomes
- Understand Linux file system security
- Configure permissions and user access
- Apply basic system hardening practices

## Context
Academic lab work – 2nd year Cyber Security student.
