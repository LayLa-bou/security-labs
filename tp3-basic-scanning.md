# TP3: Basic Scanning

## Objective
Practice basic network scanning techniques to identify active hosts, open ports, and services as part of 2nd year Cyber Security coursework.

## Lab Steps
1. Learn about network scanning concepts:
   - Host discovery
   - Port scanning
   - Service detection
2. Use **Nmap** to scan internal lab machines:
   - Identify active IPs
   - List open TCP/UDP ports
   - Detect running services
3. Document scan results:
   - Create a simple table of IPs, open ports, and services
4. Understand the importance of scanning in network security and vulnerability assessment

## Tools Used
- Nmap
- Linux terminal
- Virtual lab machines

## Learning Outcomes
- Understand how to perform network reconnaissance safely
- Identify active hosts and open services
- Document scan results for analysis

## Context
Academic lab work – 2nd year Cyber Security student.
